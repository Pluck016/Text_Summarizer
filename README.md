## About the Project

**Text Summarizer** simplifies reading and research by automatically extracting core ideas from lengthy texts. Utilizing natural language processing models, it provides both abstractive and extractive summarization capabilities, allowing users to quickly grasp key information without reading entire documents.

### Key Features
* 📄 **Document & Text Input:** Paste raw text or upload text/PDF files for instant processing.
  
* ⚡ **Fast Summarization:** Generates structured key bullet points or concise paragraph summaries.
  
* 🎛️ **Custom Length Options:** Adjust summary length and detail level based on your preference.
  
* 🌐 **Clean Web Interface:** Simple and responsive layout for seamless reading.

## Getting Started

Follow these steps to set up the project locally on your machine.

### Prerequisites

* Python 3.8 or higher
* `pip` package manager
* `git`

### Installation

1. Clone the repository:
   ```bash
   git clone [https://github.com/Pluck016/Text_Summarizer.git](https://github.com/Pluck016/Text_Summarizer.git)
Navigate to the project directory:

Bash

cd Text_Summarizer

Create and activate a virtual environment:

Bash

python -m venv venv

# On Windows:

venv\Scripts\activate

Install dependencies:

Bash

pip install -r requirements.txt

Usage

Launch the application server:

Bash

python app.py

Open your browser and navigate to:

Plaintext

[http://127.0.0.1:5000](http://127.0.0.1:5000)
Enter or paste your text into the input box and click Summarize.
